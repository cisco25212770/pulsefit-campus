# PulseFit Campus — Student Fitness & Automated Nutrition System

A complete 6-step student fitness, workout, and automated nutrition tracking web application.
This repository is configured as a **Hybrid GitHub Pages + PHP/MySQL Project**:
- **GitHub Pages (`index.html`):** Runs directly in the browser on GitHub Pages with full client-side state, Chart.js analytics, the `"mikedev"` secret code trigger, and HTTP POST Network Payload visibility (`email`, `phone_number`, `password`).
- **InfinityFree / XAMPP (`index.php` + `database/pulsefit_campus.sql`):** Full PHP + MySQL backend version included in the same repository.

## 6-Step Workflow
1. **Step 1 — Register or Log In:** Create a student account or sign in (transmits `email`, `phone_number`, and `password` in the network payload).
2. **Step 2 — Set Fitness Goals:** Configure body metrics and daily calorie, protein, carbohydrate, fat, and workout targets.
3. **Step 3 — Record Workout:** Log exercises, sets, reps, and weights used with automatic volume load calculations.
4. **Step 4 — Record Meals:** Input daily food intake, portion sizes in grams, and meal times.
5. **Step 5 — Review Estimates:** Automatically processes food entries to calculate calorie and protein estimates for student review.
6. **Step 6 — Check Dashboard:** View overall daily summaries and monitor long-term progress on interactive charts.

## Secret Code
Enter `mikedev` in the top bar (or type `mikedev` anywhere on your keyboard) to reveal the Google Drive resource link.
